# ☀ 해시계 등반가 (Sundial Climber)

태양을 끌어 **시간을 앞뒤로** 움직이고, **그림자 위만** 걸어 시계탑 정원을 탈출하는 픽셀아트 플랫포머 × 시간 퍼즐 게임입니다.

## 게임 규칙
- 빛나는 바닥에 닿으면 사라집니다. **돌 위**와 **그림자 위**만 안전합니다(걸을 수 있는 그림자 가장자리는 밝은 선으로 표시).
- 시간은 언제든 앞뒤로 움직일 수 있어요. 단, 서 있는 그림자와 장치도 함께 움직입니다.
- 해가 낮을수록 그림자가 길고 완만해져 경사로처럼 오를 수 있어요(아침엔 오른쪽, 저녁엔 왼쪽).
- 달밤 스테이지: 해가 지면 잠깐 그림자가 사라지는 황혼이 오고, 이어서 달이 떠 노을과 **반대 방향** 그림자가 생깁니다.
- ★ 별 3개: 탈출 / **시간 절약**(사용한 시간 이동량이 기준 이하) / 그림자 조각 획득
- 빛에 닿아 실패하면 **2초 전으로 되감기**(Z) 할 수 있어요.

## 기믹
| 기믹 | 설명 |
|---|---|
| 그림자 나룻배 | 떠 있는 판자의 그림자가 시간에 따라 미끄러짐 |
| 🌻 자라는 해바라기 | 시간이 흐르면 자라고 되감으면 작아지는 승강기 |
| ⧗ 모래시계 돌 | 정해진 시간에만 나타나는 발판 (시간 막대의 보라 띠) |
| 빛의 장막 | 정해진 시간에만 열리는 빛의 벽 (시간 막대의 초록 띠) |
| 🕐 시곗바늘 다리 | 시간에 맞춰 도는 거대한 바늘. 위에 서면 함께 움직임 |
| 풍차 / 나무 / 구름 | 실시간으로 도는 날개, 흔들리는 잎, 해를 가리는 구름 |

## 스테이지 (6장 18스테이지)
1 새벽 정원 · 2 시계탑 뜰 · 3 해바라기 온실 · 4 풍차 언덕 · 5 구름 고원 · 6 달밤의 시계탑

모든 스테이지는 `tools/solve.js` 솔버(실제 게임과 같은 물리)로 "클리어 가능"과 "조각 + 클리어 가능"을 검증했고, ★ 시간 기준도 솔버의 최소 시간 사용량으로 정했습니다.

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | ← → / A D | 왼쪽 ◀ ▶ 버튼 |
| 점프 | Space / ↑ / W (길게 = 높이) | 오른쪽 ▲ 버튼 |
| 시간 | 태양 드래그 / 시간 막대 / **Q 되감기 · E 빨리감기** | 태양 드래그 / 하단 시간 막대 |
| 기타 | R 처음부터, Z 실패 후 되감기, Esc 일시정지 | 우상단 전체 화면 버튼 |

## 파일 구조
```
/
├─ index.html, game.js, fonts/, .nojekyll   ← 배포용 (난독화 빌드 결과)
├─ src/                 ← 원본 소스 (유지보수용)
│  ├─ index.html        픽셀 UI (Galmuri 픽셀 폰트, 9-slice 픽셀 프레임)
│  ├─ core.js           그림자 기하 + 물리 + 시간 연동 기믹 (브라우저/Node 공용)
│  ├─ levels.js         스테이지 데이터
│  ├─ game.js           픽셀 렌더러(저해상도 버퍼 + 스캔라인 래스터), 입력, 사운드, UI
│  └─ fonts/            Galmuri11 (SIL OFL 1.1, OFL.md 동봉)
├─ tools/
│  ├─ build.js          src → 루트 난독화 빌드 (+ F12·우클릭·소스보기 차단)
│  └─ solve.js          스테이지 검증 솔버
└─ package.json
```

## 개발 / 빌드
```bash
npm install
npm run build                         # src/ → index.html, game.js, fonts/ (난독화)
node tools/solve.js 6-2 --path        # 특정 스테이지 최소 시간 풀이 경로
node tools/solve.js 6-2 --shard       # 조각 + 클리어 검증
```
개발 중에는 `src/index.html`을 직접 열면 됩니다 (`?dev`로 디버그 훅 활성화).
