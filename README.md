# ☀ 해시계 등반가 (Sundial Climber)

태양을 끌어 하루를 흘려보내고, **그림자 위만** 걸어 시계탑 정원을 탈출하는 플랫포머 × 시간 퍼즐 게임입니다.
시간은 앞으로만 흐르며 되돌릴 수 없습니다.

## 게임 규칙
- 빛나는 바닥에 닿으면 사라집니다. **돌 위**와 **그림자 위**만 안전합니다.
- 하늘의 태양을 끌거나, 하단 시간 막대를 밀거나, `E`/`Shift`를 누르고 있으면 시간이 흐릅니다.
- 해가 낮을수록 그림자가 길고 완만해져 경사로처럼 오를 수 있습니다(아침엔 오른쪽, 저녁엔 왼쪽).
- 떠 있는 판자의 그림자는 시간을 따라 미끄러지는 **나룻배**가 됩니다.
- 해가 지면 모든 그림자가 사라져 실패합니다. 달밤 스테이지에서는 황혼 뒤 달이 떠 **반대 방향** 그림자가 생깁니다.
- ★ 별 3개: 탈출 / 기준 시각 이전 도착 / 그림자 조각 획득

## 스테이지 (5장 15스테이지)
| 장 | 이름 | 핵심 요소 |
|---|---|---|
| 1 | 새벽 정원 | 그림자 걷기, 태양 끌기, 그림자 나룻배, 태양 열쇠 |
| 2 | 시계탑 뜰 | 정오의 다리, 해시계 바늘, 나룻배 갈아타기 |
| 3 | 풍차 언덕 | 회전하는 날개 그림자, 움직이는 판자 |
| 4 | 구름 고원 | 해를 가리는 구름, 흔들리는 나뭇잎 |
| 5 | 달밤의 시계탑 | 황혼의 틈, 달빛 나룻배, 하루 전체를 쓰는 피날레 |

모든 스테이지는 `tools/solve.js` 솔버로 실제 게임과 같은 물리로 클리어 가능 여부를 검증했습니다.

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | ← → / A D | 왼쪽 ◀ ▶ 버튼 |
| 점프 | Space / ↑ / W (길게 = 높이) | 오른쪽 ⌃ 버튼 |
| 시간 | 태양 드래그 / 시간 막대 / E·Shift 꾹 | 태양 드래그 / 하단 시간 막대 |
| 기타 | R 다시 시작, Esc 일시정지 | 우상단 전체 화면 버튼 |

## 파일 구조
```
/
├─ index.html        ← 배포용 (난독화 빌드 결과)
├─ game.js           ← 배포용 (난독화 빌드 결과)
├─ .nojekyll
├─ src/              ← 원본 소스 (유지보수용)
│  ├─ index.html     화면 구성·스타일
│  ├─ core.js        그림자 기하 계산 + 물리 (브라우저/Node 공용)
│  ├─ levels.js      스테이지 데이터
│  └─ game.js        렌더링·입력·사운드·UI
├─ tools/
│  ├─ build.js       src → 루트 난독화 빌드 (+ F12·우클릭·소스보기 차단)
│  └─ solve.js       스테이지 클리어 가능성 검증 솔버
└─ package.json
```

## 개발 / 빌드
```bash
npm install
npm run build          # src/ → index.html, game.js (난독화)
npm run solve          # 전체 스테이지 검증 (동적 스테이지는 수 분 소요)
node tools/solve.js 2-3 --shard   # 특정 스테이지 풀이 경로 + 조각 획득 검증
```
개발 중에는 `src/index.html`을 직접 열면 됩니다 (`?dev`를 붙이면 디버그 훅 활성화).
